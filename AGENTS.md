# Commits

- Prefix commit subjects with the primary component in brackets, e.g. `[zsh]`, `[pi]`, `[nvim]`, `[ghostty]`, or `[tmux]`.
- Infer the component from the changed paths. For an inseparable cross-component change, list components comma-separated, e.g. `[zsh, pi]`.
- Keep every commit atomic and independently reversible. Never bundle unrelated changes.
